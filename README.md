# One Sentence for a Traveler from 1800

A single sentence that explains the modern internet to someone arriving
from the year 1800, built only from things they already know: a road, a
post office, a library, a market, a letter, a cup of tea.

`main.py` (Python 3, standard library only) writes the sentence to
`/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt` when set).
The output is deterministic: the same sentence on every run.

## Entry

> Picture every library, post office, and market on earth joined by one
> invisible road, so a letter you send reaches any door in a blink, and
> its answer returns before your tea cools.

## Run

```sh
python3 main.py
cat /output/entry.txt
```
